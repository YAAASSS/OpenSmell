Which files can I import?

This explorer supports experimental generic graphs version 0.1 with exactly one Molecule and one Observation, linked by a Stimulus included in the graph; a semantic.annotations 0.1 Annotation for that molecule; and at least one flower, grass or wood measurement supported by perceptual.measurements 0.1, with a valid numeric value and min/max scale. Any referenced target must be present. Core documents and other graphs are not supported. File size limit: 1 MiB. Imported files are not saved.
